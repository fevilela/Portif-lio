# Vitrine Nagare

Portfólio da **Nagare**: sites, sistemas e agentes de IA que fazem negócios fluírem.
Instagram: [@nagare.ia](https://instagram.com/nagare.ia)

## Estrutura

```
index.html   página única (HTML + CSS + JS inline, sem build)
img/         capturas dos projetos (desktop 1200×750, celular 520px de largura)
favicon.svg  símbolo da marca
```

## Rodar localmente

Abra o `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8000
```

## Publicar

Site estático, sem build. Funciona no GitHub Pages (Settings → Pages → branch `main`, pasta `/`),
no Render (Static Site, publish directory `.`) ou na Vercel/Netlify.

## Observações

- Agente de vendas (veículos): conversa de WhatsApp simulada, com carros fictícios.
- Sistema para petshop: tela de login ilustrativa.
- Capturas do studio de beleza e do Coliseu usam a foto e a tela de login criadas para a vitrine.
- Nomes de clientes (personal trainer, revenda de veículos e studio de beleza) foram omitidos a pedido; links sob consulta.
